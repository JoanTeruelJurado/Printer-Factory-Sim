# 3D Printer Factory Simulator

A discrete-event simulation of a 3D printer production factory. You play as production planner — managing inventory, purchasing materials, scheduling manufacturing orders, and fulfilling customer demand before your wallet runs dry.

## Tech Stack

- **Factory API**: Python 3.12 + FastAPI + SQLAlchemy + SQLite (`simulator.db`, port 8000)
- **Supplier API**: Python 3.12 + FastAPI + SQLite (`supplier.db`, port 8001) — standalone service that the factory calls via HTTP
- **Frontend**: React 19 + Vite 5 + TailwindCSS v3, built and served by the Factory API

## Quick Start

```bash
# Install Python deps
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Install frontend deps (one-time)
cd frontend && npm install && cd ..

# Launch everything
./start.sh
```

Then open **http://\<VM-IP\>:8000** in your browser.

> On Multipass or a remote VM, get the IP with `hostname -I`.

To stop everything:

```bash
./stop.sh
```

## Architecture

```
Browser
  │
  ▼
Factory API :8000  (FastAPI + SQLite: simulator.db)
  │  serves React build at /
  │  exposes /api/* routes
  │
  ├── GET/POST /api/game/*          game state, advance day, export/import
  ├── GET/POST /api/manufacturing-orders/*   MO lifecycle
  └── GET/POST /api/suppliers, /api/purchase-orders
           │
           ▼  HTTP (supplier_client.py)
      Supplier API :8001  (FastAPI + SQLite: supplier.db)
           │
           ├── GET  /suppliers, /suppliers/{id}/catalog, /suppliers/{id}/pricing/{mat_id}
           ├── POST /orders          create purchase order
           ├── GET  /orders          list all orders
           ├── GET  /orders/due      orders arriving today
           ├── PUT  /orders/{id}/deliver
           ├── POST /prices/fluctuate
           └── DELETE /orders        (used by import/reset)
```

## Gameplay Loop

Each **Advance Day** triggers in sequence:
1. Supplier prices fluctuate ±10%
2. New customer demand orders are generated (1–2 per day)
3. Pending purchase orders due today are delivered to inventory
4. Released manufacturing orders are produced up to daily capacity
5. Expired unfulfilled demand orders are marked lost (€50/unit penalty)
6. Daily fixed costs deducted (€500/day + production costs)
7. Game-over check (wallet negative 3 consecutive days → game over)

**You must manually serve demand orders** before their due date to earn revenue. Orders served late earn nothing.

## Key Business Rules

| Rule | Value |
|------|-------|
| Starting wallet | €10,000 |
| Daily fixed cost | €500 |
| Variable cost per unit | €50 |
| Late/lost demand penalty | €50 per unfulfilled unit |
| Game over after | 3 consecutive days with negative wallet |
| Warehouse capacity | 10,000 units |
| Default production capacity | 10 units/day |
| Price fluctuation | ±10% daily |
